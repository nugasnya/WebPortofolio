## ✨ Tentang Proyek

**Personal Portfolio** merupakan website portofolio digital milik **Mochammad Farhan Hikmadi** yang dibuat untuk memperkenalkan profil, keterampilan, pendidikan, dan proyek dalam bidang teknologi informasi.

Website ini dikembangkan menggunakan HTML5, CSS3, dan JavaScript murni tanpa menggunakan framework CSS seperti Bootstrap atau Tailwind CSS.

Desainnya mengusung kombinasi warna pink, video sebagai latar belakang, animasi transisi, serta tata letak responsif agar nyaman digunakan pada berbagai ukuran layar.

## 🎯 Tujuan

* Memperkenalkan profil pribadi dalam bentuk digital.
* Menampilkan keterampilan dan proyek yang telah dikerjakan.
* Menerapkan HTML semantik untuk membangun struktur halaman.
* Menggunakan CSS untuk mengatur layout, warna, animasi, dan responsivitas.
* Mengimplementasikan JavaScript untuk interaksi pemutaran video dan musik.

## 🛠️ Teknologi yang Digunakan

* **HTML5** — membangun struktur halaman menggunakan elemen semantik.
* **CSS3** — mengatur tata letak, warna, animasi, efek visual, dan media query.
* **JavaScript** — mengelola interaksi tombol dan pemutaran media.
* **Visual Studio Code** — editor untuk pengembangan website.
* **Live Server** — menjalankan website secara lokal selama pengembangan.

> Proyek ini tidak menggunakan framework CSS eksternal. Seluruh styling dibuat menggunakan CSS murni.

## 💻 Cara Menjalankan Proyek

1. Unduh atau salin seluruh folder proyek ke komputer.
2. Buka folder proyek menggunakan Visual Studio Code.
3. Pastikan file HTML, CSS, JavaScript, video, gambar, dan audio berada pada lokasi yang sesuai.
4. Pasang ekstensi **Live Server** jika belum tersedia.
5. Klik kanan `index.html`, lalu pilih **Open with Live Server**.
6. Klik tombol **Buka Portofolio** untuk menuju halaman profil.
7. Gunakan tombol pemutar media untuk menjalankan video dan musik.

Website juga dapat dibuka langsung melalui browser, tetapi Live Server direkomendasikan selama pengembangan.

## 📱 Responsivitas

Website dirancang menggunakan CSS Flexbox, ukuran font fleksibel, dan media query untuk menyesuaikan tampilan berdasarkan lebar layar.

| Perangkat  | Penyesuaian                                                                        |
| ---------- | ---------------------------------------------------------------------------------- |
| Desktop    | Konten utama dan tombol ditampilkan secara horizontal jika ruang mencukupi.        |
| Tablet     | Ukuran teks, jarak, dan padding disesuaikan.                                       |
| Smartphone | Tombol utama disusun vertikal dan konten menggunakan ruang layar yang lebih kecil. |
